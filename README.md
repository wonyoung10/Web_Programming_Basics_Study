0828 (1주차 학습)

주제: HTML 역사, 기초 문법

HTML 기본 구조

<html> : HTML 문서 시작과 끝

<head> : 문서 정보, 제목(title) 포함

<body> : 실제 화면에 보이는 본문 내용

텍스트 관련 태그

<b> : 굵은 글씨

<font> : 글자 색상, 크기, 글꼴 지정

링크 & 이미지 태그

<a href="주소">텍스트</a> : 하이퍼링크

<a href="주소"><img src="이미지경로"></a> : 이미지를 클릭하면 링크로 이동

0904 (2주차 학습)

주제: 제목 태그, 주석, 단락, 목록, 표

제목 태그

<h1> ~ <h6> : 제목 크기 (h1이 가장 큼)

다른 태그와 혼합 가능 → <b>, <i>, <small>, <sub>, <sup>, <ins>

주석 태그

<!-- 내용 --> : 화면에는 표시되지 않고 코드에만 남음

구분선 & 단락 태그

<hr> : 수평 구분선

<p> : 단락 구분

<del> : 취소선

목록 태그

<ol> : 순서 있는 목록 (Ordered List)

<ul> : 순서 없는 목록 (Unordered List)

<li> : 목록 항목

중첩 가능 (대분류 - 중분류 구조 작성 가능)

표 (Table) 태그

<table border="1"> : 표 생성

<tr> : 행(Row)

<td> : 일반 셀

<th> : 제목 셀 (굵게, 가운데 정렬)

colspan : 열 병합

rowspan : 행 병합
